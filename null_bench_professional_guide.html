Null Bench کس کے لیے ہے اور کیسے استعمال ہوتا ہے؟

خاص پیشہ ورانہ سافٹ ویئر: یہ عام روزمرہ گفتگو، ہر قسم کی AI سرچ، گاڑی کی تشخیص یا موبائل کالنگ کا ٹول نہیں۔ یہ گراف تھیوری اور نیٹ ورک سائنس میں کسی نیٹ ورک کی ساخت کو مناسب بے ترتیب (Null) نیٹ ورکس کے مقابلے میں جانچنے کے لیے بنایا گیا ہے۔ صفحہ ہر کسی کے لیے کھلا ہے، لیکن نتائج کی سائنسی تشریح متعلقہ مہارت چاہتی ہے۔

کن شعبوں اور پیشہ ور افراد کے لیے؟

  • نیٹ ورک سائنس اور گراف تھیوری: یونیورسٹی محققین، ریسرچ فیلو، شماریات دان اور ڈیٹا سائنسدان جو ساختی پیٹرن کی جانچ کرتے ہیں۔
  • کمپیوٹر سائنس / سافٹ ویئر ریسرچ: گراف الگورتھم، الگورتھم کی جانچ، نیٹ ورک ٹاپولوجی اور سائنسی طریقہ کار پر کام کرنے والے افراد۔
  • سماجی علوم: رضامندی سے حاصل کردہ غیر حساس ربط کے ڈیٹا میں کمیونٹی یا مثلث نما ساخت پر ابتدائی تحقیق کرنے والے محققین۔
  • حیاتیاتی نیٹ ورکس: مجاز جینیاتی، پروٹین یا تعاملاتی نیٹ ورکس کی ساخت کی تحقیق؛ طبی یا حیاتیاتی دعویٰ آزاد تجرباتی تصدیق مانگتا ہے۔
  • سائبر سیکیورٹی کی تحقیق: اجازت یافتہ نیٹ ورک ٹاپولوجی کی شماریاتی جانچ؛ یہ حملے یا ہیکنگ کا قطعی شناختی آلہ نہیں۔
  • ٹرانسپورٹ، لاجسٹکس اور انجینئرنگ: مجاز روٹ یا کنکشن گراف کی ساخت کا تقابل؛ یہ حقیقی راستے یا تعمیر کی حفاظت کا سرٹیفکیٹ نہیں۔
  • اساتذہ اور اعلیٰ تعلیم کے طلبہ: صرف مثالوں اور تحقیقی مشقوں کے لیے، حقیقی نتائج کو حتمی سائنسی ثبوت قرار دیے بغیر۔

کیا یہ براؤزر میں چلتا ہے یا Python میں؟

موجودہ پبلک ٹیسٹ Android، iPhone یا کمپیوٹر کے جدید ویب براؤزر میں چلتا ہے۔ یہ صفحہ HTML (ساخت)، CSS (ڈیزائن)، اور JavaScript (حسابات) استعمال کرتا ہے۔ گراف بنانا، degree-preserving double-edge swapping، clustering/transitivity اور null distribution کا حساب براؤزر کے JavaScript میں ہوتا ہے۔ Python، Termux، GitHub اکاؤنٹ یا الگ ایپ انسٹال کرنا ضروری نہیں۔

Python سے مستقبل میں الگ تحقیق یا الگ اسکرپٹس بن سکتے ہیں، لیکن اس پبلک ٹیسٹ کے لیے Python کی لازمی یا فعال سروس کا دعویٰ درست نہیں۔ ویب سائٹ کے دیگر E-ZERO ماڈیولز کا ٹیکنالوجی اسٹیک مختلف ہو سکتا ہے۔

یہ حساب اصل میں کیا کرتا ہے؟

جاوا اسکرپٹ پہلے آپ کے گراف کا transitivity/clustering پیمانہ نکالتا ہے۔ پھر موجودہ کنکشنز کو بدل کر ایسے بہت سے نئے گراف بناتا ہے جن میں ہر نوڈ کے کنکشنز کی تعداد (degree) برقرار رہتی ہے؛ بعد میں ان کے clustering پیمانوں کی تقسیم سے اصل پیمانے کا تقابل کرتا ہے۔ یہ کسی بیماری، خراب گاڑی، دھوکے یا سیکیورٹی حملے کا قطعی فیصلہ نہیں کرتا۔

سائنسی اور ڈیٹا حدود: یہ ہر قسم کے نیٹ ورک کے لیے مناسب Null Model نہیں۔ Self-loops نظر انداز ہوتے ہیں، دہرائے ہوئے کنکشن گراف میں ایک کنکشن بن جاتے ہیں، کم یا ناکام swap attempts مناسب بے ترتیبی کی ضمانت نہیں، اور اس عوامی ورژن میں random seed یا باقاعدہ p-value کنٹرول موجود نہیں۔ اگر null standard deviation صفر ہو تو z-score قابلِ حساب نہیں ہوتا، اس لیے UI میں N/A دکھایا جاتا ہے؛ اسے خودکار طور پر عدمِ فرق کا ثبوت نہ سمجھیں۔

پرائیویسی: گراف کا بنیادی حساب اسی براؤزر میں ہوتا ہے؛ موجودہ مرکزی ویب سائٹ Google Analytics 4 کے ذریعے وزٹ اور کچھ شماریاتی event metadata بھیجتی ہے۔ حساس، ذاتی یا غیر مجاز رابطوں کا ڈیٹا پیسٹ نہ کریں۔

ENGLISH · PROFESSIONAL RESEARCH REFERENCE

Who should use Null Bench, and how does it work?

Specialized audience, publicly accessible: Null Bench is for researchers, data scientists, graph-theory and network-science specialists, educators and trained students. It is not a general chatbot, AI search engine, vehicle fault scanner, physical sensor monitor or safety-certified decision system.

Appropriate professional applications

  • Network science / graph theory: Assess graph structure relative to a degree-preserving reference ensemble.
  • Computer science and algorithms: Explore topology, transitivity, graph-randomization assumptions and computational statistics.
  • Social science: Explore non-sensitive, consented relationship graphs; no individual profiling or causal conclusions.
  • Biology: Explore permitted interaction-network structure; biological claims need independent experimental validation.
  • Cybersecurity research: Study authorized connectivity graphs, not identify an intrusion or certify a system as secure.
  • Logistics / transport / engineering: Compare abstract connection structures, not certify the safety of routes or equipment.
  • Teaching: Demonstrate null hypotheses, randomized controls and limitations of network statistics.

Technology: JavaScript in a browser, not a Python requirement

The existing public graph test uses HTML for page structure, CSS for layout, and JavaScript for computation. The page calculates graph adjacency, double-edge swaps, transitivity, a sampled null distribution, a histogram and the displayed statistics locally in the user's browser. Use a modern mobile or desktop browser; no Python interpreter, Termux, notebook, account or separate app installation is required for this test.

Python could be used in an independent offline research workflow, but the current public #try runner is JavaScript; no general Python execution API is implied by this guide.

Step-by-step: one real browser exercise

  1. Open Run Null Bench. In Demo network, pick Modular network or Random network, then press Generate Demo Network. Or choose Custom edge list and paste an authorized graph.
  2. For custom data, enter one pair of node identifiers per line, separated by a comma or space; for example a,b, a,c, b,c, c,d. Each pair represents one undirected edge. No direct file-upload control is required.
  3. Set Null samples to 200 (allowed 20–2000) and Swap attempts / sample to 300 (allowed 10–5000). Larger values can take longer on a mobile phone.
  4. Press Run Null-Model Test. The browser samples rewired graphs that preserve each node's degree, then evaluates their transitivity.
  5. Read Nodes / edges, Observed clustering, Null mean ± SD, the sampled 95% null interval, z-score and the histogram. “Outside the interval” is a research signal relative to this model, not a confirmed cause.
  6. Document the data source, constraints, graph preparation, sample count, attempted swaps, outputs and limitations. Seek expert replication for consequential findings.

How to interpret the test correctly

Displayed outputMeaning and caution
Observed clusteringGlobal transitivity of the entered undirected graph; not a measure of disease, faults or causation.
Null mean ± SDMean and sample standard deviation of the randomized transitivity values; only meaningful under model assumptions.
95% null intervalApproximate sampled 2.5th–97.5th percentile range; not a confidence interval on a real-world cause.
z-scoreDeviation relative to sampled SD. If SD is zero, the interface displays N/A (undefined z-score); this is a degenerate simulation, not proof of equivalence.
Histogram / verdictRelative placement of observed data and sampled randomizations; no certified statistical p-value or universal diagnosis.

Methodological limits

The tool builds a simple undirected graph: self-loops are ignored, duplicate edges collapse in the adjacency representation, and extra columns beyond the first two node identifiers are not used. Random double-edge swaps preserve node degrees but finite accepted swaps do not guarantee uniform or independent graph samples. The public interface does not expose a random seed field or a formal p-value. The UI's Nodes / edges count reports distinct undirected graph edges after de-duplication and ignoring self-loops, not the number of submitted rows. Re-check modeling assumptions, degree distribution and mixing before publishing scientific claims.

Privacy: The graph calculation itself runs in the browser. The main public site currently uses Google Analytics 4 and sends visit/event statistic metadata. Do not paste confidential networks or personal identifiers. This documentation page adds no analytics code, account sign-in or server-side graph upload.

المهن والمجالات المناسبة

  • علوم الشبكات ونظرية الرسوم: اختبار أنماط الترابط والتجمع مقابل نموذج مرجعي عشوائي.
  • علوم الحاسوب والخوارزميات: دراسة بنية الشبكات وخوارزميات إعادة توصيل الروابط.
  • العلوم الاجتماعية: فحص شبكات العلاقات المصرّح بها ومن دون بيانات شخصية.
  • الشبكات الحيوية: تحليل البنية فقط، مع اشتراط تحقق بيولوجي مستقل لأي استنتاج تجريبي.
  • أبحاث الأمن السيبراني: استكشاف البنية في الشبكات المصرّح بها، دون إصدار حكم قطعي بوجود هجوم.
  • النقل واللوجستيات والهندسة والتعليم: مقارنة رسوم الاتصالات لأغراض البحث والتدريب، لا لإصدار شهادات سلامة فعلية.

هل تعمل في المتصفح أم في Python؟

تعمل النسخة العامة داخل متصفح الهاتف أو الحاسوب بواسطة HTML وCSS وJavaScript. تنفَّذ حسابات الشبكة وإعادة التوصيل العشوائي والإحصاءات والرسوم البيانية بوساطة JavaScript داخل المتصفح. لا يلزم تثبيت Python أو Termux أو تطبيق منفصل. يمكن استخدام Python في عمل بحثي مستقل، لكن ذلك ليس محرك اختبار #try المنشور حالياً.

طريقة التشغيل خطوة بخطوة

  1. افتح صفحة الاختبار وانتقل إلى 01 — Run a test.
  2. اختر Modular network أو Random network من Demo network، ثم اضغط Generate Demo Network. أو اختر Custom edge list لبيانات رسم مصرح بها.
  3. في Edge list أدخل رابطاً واحداً في كل سطر، مثلاً a,b أو a b. هذه شبكة بسيطة غير موجهة وغير موزونة.
  4. اضبط Null samples على 200 (المدى 20–2000)، وSwap attempts / sample على 300 (المدى 10–5000).
  5. اضغط Run Null-Model Test. يقارن المتصفح التجمع المرصود بنماذج عشوائية تحافظ على عدد روابط كل عقدة.
  6. اقرأ Nodes / edges (عدد العقد والروابط الفريدة غير الموجهة بعد حذف التكرار والروابط الذاتية) وObserved clustering وNull mean ± SD و95% null interval وz-score والرسم التكراري. الاختلاف يعني إشارة للاستقصاء، لا برهاناً على السبب.
  7. دوّن مصدر البيانات والروابط والافتراضات وعدد العينات ومحاولات التبديل والقيود، واطلب تكرار البحث بصورة مستقلة عند وجود ادعاءات مهمة.

قيود المنهج والخصوصية

تُتجاهل الروابط الذاتية وتندمج الروابط المكررة في الرسم، ولا تضمن المحاولات العشوائية المحدودة عينات موحّدة أو مستقلة إحصائياً. لا يوجد حقل عام للبذرة العشوائية أو اختبار قيمة p-value رسمي في هذه الواجهة. إذا كان الانحراف المعياري صفراً، فإن قيمة z-score تكون غير معرّفة، لذا تعرض الواجهة N/A، ولا يُعد ذلك دليلاً على التماثل. احرص على التحقق من صلاحية نموذج المقارنة.

الخصوصية: تجري حسابات الرسم في المتصفح، لكن الصفحة الرئيسية تستخدم Google Analytics 4 لإرسال بيانات زيارات ومقاييس أحداث إحصائية؛ لا تُدخل بيانات شخصية أو شبكات سرية. هذه الصفحة الإرشادية نفسها لا تضيف أدوات تتبع أو ميزة رفع الملفات.

Evidence and operating boundary

Null Bench is an exploratory, computational statistical method, not a causal proof. Mathematical degree-preservation, a displayed browser statistic, replicated empirical evidence and independent physical validation are different levels of evidence. The output should never be presented as a certified clinical, automotive, cybersecurity or engineering decision.
